01Ringkasan

Proyek ini mengembangkan game tembak pesawat 3D berbasis satu file HTML. Setelah permainan dimulai, pemain dapat menekan tombol Bertanya, mengucapkan pertanyaan tentang permainan, lalu menerima jawaban yang dibacakan browser.

Computer vision memakai MediaPipe Hands untuk menemukan landmark tangan dan mengenali gerakan cubit. NLP berupa klasifikasi maksud berbasis kata kunci setelah ucapan diubah menjadi teks oleh Web Speech API. Tidak ada model NLP besar atau model YOLO di dalam proyek.

Tujuan dan ruang lingkup

Tujuannya menggabungkan game 3D dengan interaksi kamera dan bahasa alami sederhana. Laporan ini membahas teori, implementasi, model dan API, langkah pembuatan, perangkat, kebutuhan internet, penggunaan di HP, serta cara memakai kamera dan mikrofon.

02Teori yang digunakan

Computer vision

Computer vision memungkinkan komputer menafsirkan gambar atau video. Kamera menghasilkan rangkaian frame. Model deteksi tangan menemukan area telapak, lalu model landmark memperkirakan titik sendi dan ujung jari. MediaPipe Hands mengeluarkan 21 landmark dengan koordinat yang dinormalisasi terhadap ukuran gambar [1, 2].

Gerakan cubit ditentukan dari jarak ujung ibu jari dan telunjuk dibandingkan ukuran telapak, sehingga ambang tetap stabil ketika tangan mendekat atau menjauh dari kamera.

Natural Language Processing

NLP adalah teknik untuk mengolah bahasa manusia. Alurnya: pengenalan ucapan, pengenalan maksud, penyusunan jawaban, lalu text-to-speech. Pengenalan ucapan dan sintesis suara disediakan browser lewat Web Speech API [3].

Bagian NLP khusus game memakai aturan dan pencocokan kata kunci, bukan model machine learning bahasa. Pertanyaan dikelompokkan ke maksud seperti skor, nyawa, level senjata, bos, atau tips.

Coba sendiri: deteksi cubitan

Geser untuk mengubah jarak ibu jari (4) ke telunjuk (8), dibagi jarak titik 0 ke 9.

Rasio: 0.50 Terbuka

Cubitan terdeteksi di bawah 0,22 selama lima frame. Jari harus terbuka melewati 0,36 sebelum cubitan berikutnya dikenali (histeresis).

03Penerapan pada game

Mainkan game

Game Tembak Pesawat dapat dimainkan langsung di bawah ini. Izinkan akses kamera dan mikrofon pada browser jika ingin mencoba kendali tangan dan fitur Bertanya.

Jika game tidak tampil, buka game di tab baru.

Kendali dengan kamera

  • Halaman meminta izin lewat getUserMedia dan menampilkan pratinjau kamera kecil.
  • MediaPipe memproses satu tangan dengan modelComplexity 0, minDetectionConfidence 0.65, dan minTrackingConfidence 0.55.
  • Ujung telunjuk (landmark 8) diterjemahkan ke target pesawat. Arah horizontal dibalik agar terasa seperti cermin, dan posisi dibatasi di area permainan.
  • Kerangka tangan digambar dengan garis dan titik hijau pada pratinjau.
  • Cubitan memilih tombol di layar menu serta menjeda atau melanjutkan permainan.
  • Tembakan berlangsung otomatis. Mouse, sentuhan, tombol panah, dan WASD tetap tersedia.

Tanya pilot dengan bahasa

Tombol Bertanya memulai pengenalan ucapan satu kali dalam Bahasa Indonesia (id-ID). Jika maksud tidak dikenali, pilot menyebutkan jenis pertanyaan yang bisa dijawab. Jawaban dibacakan lewat SpeechSynthesisUtterance, mengikuti suara id-ID yang tersedia di browser dan sistem operasi.

05Cara membuat proyek

  1. Siapkan struktur HTML. Antarmuka game, kanvas Three.js, HUD, menu, tombol kamera, dan tombol Bertanya.
  2. Muat pustaka dari CDN. Three.js dan MediaPipe Hands. Buat adegan 3D, kamera, renderer, pesawat, musuh, peluru, efek, dan loop animasi.
  3. Aktifkan kamera. Panggil getUserMedia, inisialisasi Hands, kirim frame lewat hands.send, lalu pakai multiHandLandmarks untuk gerak pesawat dan overlay hijau.
  4. Hitung rasio cubit. Gunakan ambang tutup dan buka yang berbeda, serta beberapa frame stabil agar gerakan sesaat tidak memicu aksi.
  5. Tambahkan tombol Bertanya. Mulai SpeechRecognition satu kali dengan id-ID, ubah transkrip menjadi intent, susun jawaban dari skor, nyawa, senjata, dan bos, lalu bacakan lewat speechSynthesis.
  6. Simpan dan publikasikan. Skor terbaik disimpan di localStorage. Untuk publikasi, unggah ke hosting HTTPS seperti GitHub Pages.

07Internet dan HP

Kebutuhan internet

Game tidak sepenuhnya offline. Three.js, MediaPipe Hands, dan font dimuat dari CDN, sehingga internet diperlukan saat halaman dibuka. Pengenalan ucapan Chrome dapat memakai layanan server dan tidak berfungsi offline secara bawaan [3].

Untuk versi offline, semua pustaka dan model harus disertakan lokal, dan pengenalan ucapan diganti mesin offline.

Menjalankan di HP

Game dapat dicoba lewat GitHub Pages karena memakai HTTPS. Layar sentuh berfungsi sebagai input pointer, dan kamera depan dapat dipakai jika izin diberikan. Mode potret atau perangkat berspesifikasi rendah dapat menurunkan kelancaran.

Fitur Bertanya paling mungkin berjalan di Chrome dengan koneksi internet. Uji langsung di perangkat tujuan sebelum publikasi final.

08Kamera dan mikrofon

Kamera untuk kendali

  • Buka lewat localhost, HTTPS, atau GitHub Pages, lalu izinkan kamera. Izin dapat diatur per situs [4].
  • Arahkan telunjuk ke kamera; pesawat mengikuti ujung telunjuk.
  • Cubit ibu jari dan telunjuk untuk memilih menu atau menjeda dan melanjutkan.
  • Klik Gunakan keyboard untuk mematikan kamera dan beralih ke panah atau WASD.

Mikrofon untuk bertanya

  • Klik Bertanya saat bermain atau di layar hasil. Mikrofon baru mendengarkan setelah tombol ditekan.
  • Ucapkan satu pertanyaan, misalnya “tampilkan skor terbaik”, “berapa nyawa”, “senjata level berapa”, atau “beri tips”.
  • Pilih Allow while visiting the site agar izin berlaku pada kunjungan berikutnya di origin yang sama.
  • Pastikan mikrofon yang benar dipilih di pengaturan Chrome.

09Batasan dan kesimpulan

Proyek ini menunjukkan integrasi computer vision dan NLP sederhana dalam satu game browser. MediaPipe Hands menyediakan koordinat jari untuk kendali dan visualisasi tangan. Web Speech API menangani pengenalan ucapan dan pembacaan jawaban, sementara logika NLP game mencocokkan intent dengan aturan yang mudah diperiksa.

Karena intent memakai kata kunci, variasi kalimat yang tidak cocok menghasilkan jawaban cadangan. SpeechRecognition memiliki dukungan browser terbatas dan, di Chrome, dapat bergantung pada layanan daring [3].
